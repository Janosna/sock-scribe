# Sock Creator Studio

Erstelle einen modernen, hochwertigen und vollständig responsiven Online-Shop für eine Marke, die personalisierte und fertig bestickte Socken verkauft.

ZIELGRUPPE:

Menschen, die besondere, persönliche und originelle Socken als Geschenk oder für sich selbst kaufen möchten. Der Shop soll emotional, modern und hochwertig wirken – nicht wie ein klassischer Bastelshop.

DESIGN:

- Minimalistisch, modern und hochwertig

- Warme, freundliche Farbwelt

- Hintergrund überwiegend Off-White / Creme

- Schwarze bzw. sehr dunkle Schrift

- Akzentfarbe dezent einsetzen, z. B. warmes Rot, Terracotta oder Koralle

- Große hochwertige Produktbilder

- Viel Weißraum

- Runde Ecken bei Karten und Buttons

- Moderne, gut lesbare Schrift

- Mobile First

- Sehr schnelle und übersichtliche Benutzerführung

- Keine überladenen Animationen

- Dezente Hover- und Scroll-Animationen

- Der Shop soll wie eine echte etablierte Fashion-/Lifestyle-Marke wirken

WICHTIG:

Der Shop soll zunächst mit realistischen Platzhalterbildern und Beispieldaten funktionieren. Verwende keine zufälligen generischen Produktnamen. Erstelle eine klare Struktur, die später einfach mit meinen echten Produkten, Bildern und Markendaten ersetzt werden kann.

WICHTIG:

Die Datenbank muss so strukturiert sein, dass mehrere Produkte und mehrere personalisierte Artikel innerhalb einer Bestellung möglich sind.

SICHERHEIT:

- Keine geheimen API Keys im Frontend.

- Supabase Row Level Security verwenden.

- Admin-Bereich muss geschützt sein.

- Kunden dürfen nur ihre eigenen Bestellungen sehen.

- Zahlungsstatus darf nicht vom Frontend manipuliert werden.

STRIPE:

Bereite die Architektur für Stripe vor.

Der Ablauf soll später sein:

Kunde erstellt Warenkorb

→ Checkout wird erstellt

→ Stripe Payment

→ erfolgreiche Zahlung

→ Stripe Webhook

→ Bestellung wird in Supabase als bezahlt markiert

→ Produktionsauftrag wird erstellt

→ Kunde bekommt Bestellbestätigung

NIEMALS eine Bestellung allein aufgrund eines Frontend-Callbacks als bezahlt markieren.

Der Zahlungsstatus muss serverseitig über Stripe verifiziert werden.

Verwende eine saubere und wartbare React/TypeScript-Struktur.

Komponenten wiederverwenden.

Produktdaten nicht direkt in Komponenten hardcoden, sondern aus Supabase laden.

Die Anwendung muss vollständig responsive sein und besonders auf Smartphones sehr gut funktionieren.
